## 📌 Cómo usar este repositorio

1. Navega a la sección que necesitas usando los enlaces de arriba.
2. Copia el prompt que deseas usar.
3. Pégalo en la herramienta indicada (Claude, ChatGPT, PlantText, etc.).
4. Ajusta los parámetros entre corchetes `[COMO ESTE]` según tu caso.
